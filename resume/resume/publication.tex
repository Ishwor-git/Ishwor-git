    {IsoNet: Multimodal Audio-Visual Target Speech Extraction with
Spatial Conditioning for Compact Microphone Arrays} % Title
    {Journal of Innovation in Engineering Innovation (JIEE)} % Location
    {Accepted for publication} % Date(s)
    {
      \begin{cvitems} % Description(s)
        \item {Designed a multimodal target speech extraction system combining complex STFT features, GCC-PHAT spatial cues, and face-conditioned visual embeddings within a U-Net mask estimation network for 4-microphone arrays.}
        \item {Achieved 9.31 dB SI-SDR (a 4.85 dB improvement over the mixture) on a hard -1 to 10 dB SNR test set, outperforming oracle delay-and-sum and MVDR beamformers, which degraded performance by 4.82 dB and 6.08 dB respectively.}
        \item {Demonstrated consistent gains from visual conditioning and GCC-PHAT features via ablation studies, establishing a compact-array, face-selectable speech extraction baseline.}
      \end{cvitems}
